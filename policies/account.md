# Account and Password

To reset a password, use the **Forgot password** link on the sign-in page. A
reset link is emailed to the address on the account and is valid for 60 minutes.

If the reset email does not arrive, check the spam folder first. Support cannot
set or read a password on a customer's behalf — the reset link is the only way.

Email addresses on an account can be changed from **Account → Details**.
Changing the account email does not change the address on orders already placed.

Accounts can be closed on request. Order history is retained for seven years for
tax purposes, as required by law.
